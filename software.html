Software, Models & Datasets

The SVARNA research toolkit — open platforms, code, models and corpora

Much of this work was carried out with the CLLT lab; datasets and code are openly licensed where noted.

Applications & Platforms

Greek NLP Swiss Knife

A unified portal hosting 10 containerized AI applications (~200k lines of code) for Modern Greek linguistics, classical studies, and digital humanities research, developed with cloud computing support from Microsoft. Role: Principal Architect & Main Developer.

Live ↗

MuVeS

AI research assistant platform for paper discovery, automated literature reviews, interactive chat, paper analysis. Role: One of three main developers.

Live ↗

MEDEA-NEUMOUSA

AI platform for classical philology: (1) Translation between 18 ancient languages, (2) Knowledge graph extraction (RDF/TTL), (3) Zeugma neuro-symbolic reasoning (LLM+Prolog), (4) Emotion knowledge graphs, (5) Semantic analysis. Role: Main developer.

Live ↗

Plot Analyzer

Bidirectional neuro-symbolic narrative analysis platform with 8-stage hybrid architecture: neural perception via LLMs, symbolic reasoning based on 5 narrative theories (Aristotelian Poetics, Russian Formalism, etc.), bidirectional feedback loop, 14-type conflict taxonomy, and chunking & reconciliation for long texts. Role: Main developer.

Live ↗Code

Simasia-Studio (TextCraft)

AI text editor and translator with RAG for domain-specific translation, grammar/style analysis, track changes output. Role: Main developer.

Live ↗

RAG-to-Coq Pipeline

Historical event extraction with 10 extraction modes, 5 LLM support, translation to Coq for formal verification. Role: Main developer.

Code

NATS

NLP analysis suite: document embeddings, NER (19 types), network analysis. Role: Main developer.

Live ↗Code

Linguistic Distance Calculator

7-dimension language distance measurement. Role: Main developer.

Live ↗Code

Greek Curriculum Ontology Extractor

LLM-based ontology extraction with RAG. Role: Main developer.

Code

Syntax-Expert

Multi-framework syntactic analysis (Minimalism, HPSG, LFG, DS). Role: Main developer.

Code

DI_detector

Greek dialect identification. Role: Main developer.

Code

TextCraft Terminography

AI-assisted terminography platform: automatic term extraction from corpora (PDF/DOCX/CSV) per ISO 1087-1:2000, neuro-symbolic definition evaluation, RAG pipeline with OpenAI embeddings, multi-LLM support (Gemini, Claude, GPT-4o, DeepSeek), ELETO terminology scraper. Role: Main developer.

Live ↗

Svarna: Greek Corpus Workbench

Corpus linguistics workbench for Modern Greek: KWIC concordancing, frequency and n-gram analysis, discourse markers, keyness (log-likelihood), regex search, and LLM-assisted pragmatic analysis over 500M+ words across six corpora. Role: Main developer.

Live ↗Code

Greek Rhyme System

AI-powered identification and generation of rhyme patterns in Modern Greek poetry: full rhyme taxonomy (M/F2/F3, RICH, IDV, MOS, IMP), multi-LLM analysis with RAG corpus retrieval and a deterministic phonological verification loop. Role: Main developer.

Live ↗

Greek Dialect Generator

Text generation in four Greek dialects (Pontic, Cretan, Northern Greek, Cypriot) using LoRA adapters fine-tuned on GRDD+ (23k+ examples) over Llama 3.1, Llama 3, and Krikri base models, served with 4-bit quantization. Role: Main developer.

Live ↗Code

Voyant-NLP

Text analysis and embeddings lab: word frequencies, concordance, collocates, Word2Vec/FastText training with analogies, NER, POS tagging, topic modeling, sentiment analysis, and document clustering. Role: Main developer.

Live ↗
